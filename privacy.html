개인정보처리방침 (학지 파일전송방)

시행일: 2026년 10월 19일

1. 앱이 하는 일

학지 파일전송방은 사용자의 구글 드라이브에 있는 지정된 폴더(태블릿 자료)의 파일 목록과 파일을 웹 브라우저에서 보여주는 도구입니다.

2. 접근하는 정보

  • 구글 계정 로그인으로 받은 드라이브 읽기 권한을 사용합니다.
  • 앱은 지정된 폴더의 파일 목록과 파일 내용을 읽기만 합니다. 파일을 수정하거나 삭제하지 않습니다.

3. 자료의 저장 위치

  • 받은 파일은 사용 중인 기기(브라우저)의 저장공간에만 보관합니다.
  • 한 달 동안 열지 않은 파일은 기기에서 자동으로 삭제합니다. 필요하면 다시 받을 수 있습니다.
  • 앱 운영자는 사용자의 파일이나 구글 계정 정보를 서버에 저장하지 않습니다.

4. 제3자 제공

수집하거나 저장한 정보를 제3자에게 판매하거나 제공하지 않습니다.

5. 로그인 정보

구글 로그인 정보는 구글이 관리합니다. 앱은 드라이브를 읽기 위한 접근 토큰만 기기에 보관하며, 로그아웃하거나 앱 데이터를 지우면 함께 삭제됩니다.
